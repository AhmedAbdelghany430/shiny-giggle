# Product Landing Page (Arabic)

Responsive Arabic product landing page: hero banner, feature highlights, pricing section and a purchase button.

## Tech
HTML5, CSS3

## Files
product landing page.html

## How to use
Built with CSS Grid and Flexbox, with gradients and hover effects.

## Run locally
Download or clone the repo and open the main HTML file in a browser. No install needed.
